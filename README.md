# Firefly Nocturne · 반딧불의 야상곡

Unity Particle System으로 만든 약 5분 35초의 불꽃놀이 과제입니다.
작은 반딧불의 빛이 숲과 호수 위에서 커다란 별이 되는 모습을 표현했습니다.

## 실행

1. Unity Hub에서 이 저장소의 루트 폴더를 추가합니다. `Assets`, `Packages`, `ProjectSettings`가 있는 폴더입니다.
2. **Unity 6000.3.23f1**으로 엽니다. 첫 실행은 패키지와 음원 임포트에 시간이 걸릴 수 있습니다.
3. `Assets/Scenes/GameScene.unity`를 열고 **Play**를 누릅니다.
4. Game 뷰를 **16:9**, 가능하면 **Maximize On Play**로 설정합니다. 초반에는 반딧불과 제목이 나타나며 첫 폭발은 약 13초에 시작합니다.
5. 음악이 끝난 뒤 마지막 잔광이 사라지고 종료 문구가 나타납니다. 앱을 강제로 닫지 않으므로 마지막 장면을 감상하거나 다시 재생할 수 있습니다.

| 키 | 동작 |
| --- | --- |
| Space | 음악과 연출 함께 일시정지 / 재개 |
| R | 처음부터 다시 재생 |
| M | BGM 음소거 / 해제 |
| H | 제목·시간·조작 안내 숨기기 / 표시 |

## 연출 의도

주색은 따뜻한 황금색과 연두색입니다. 빨강은 전체 발사 중 10% 미만으로 사용하며 크기도 작게 조절했습니다.
밤하늘의 초승달, 여러 겹의 산 능선, 소나무 숲, 갈대, 잔잔한 호수와 수면에 번지는 불빛으로 동화 같은 분위기를 구성했습니다.
강한 폭발음은 추가하지 않고 제공된 BGM의 분위기를 살렸습니다.

| 구간 | 연출 |
| --- | --- |
| 00:00–00:32 | 반딧불이 깨어나고 작은 빛이 흩어지는 도입 |
| 00:32–01:30 | 노랑 불꽃이 간격을 두고 피어나는 전개 |
| 01:30–02:38 | 연두색과 노랑색의 교차, 원형·이중 고리·낙하형 불꽃 |
| 02:38–03:55 | 여러 높이에서 번갈아 펼쳐지는 숲의 축제 |
| 03:55–05:02 | 발사 밀도와 조합이 늘어나는 절정 |
| 05:02–05:26 | 좌우 대칭의 노랑·연두 피날레 |
| 05:26–05:35 이후 | 작은 반딧불형 불꽃과 잔광이 사라지는 마무리 |

음원의 실제 PCM 샘플을 0.2초 단위로 분석해 음량과 상승 폭을 측정했습니다. 각 연출 구간에서 가까운 강세를 골라 폭발 시점을 배치했으며, 음악과 같은 오디오 DSP 시계를 사용해 연출 시간이 프레임 속도에 따라 밀리지 않게 했습니다.

## 구현과 수정

- `Assets/FireflyFestival/Settings/An Old Legend Score.asset`: 음원, 3색 팔레트, 시간순 발사 큐, 구간 제목, 분석된 음량 데이터. Inspector에서 색과 각 발사의 시간·위치·모양·크기를 수정할 수 있습니다.
- `Assets/FireflyFestival/Prefabs/Firefly Shell.prefab`: 상승 불꽃, 폭발, 잔불, 중심 섬광의 네 가지 Particle System. Trails, Color/Size over Lifetime, Gravity, Drag, Noise 모듈을 사용합니다.
- `Assets/FireflyFestival/Scripts/FireworksDirector.cs`: 음악 재생, 시간별 발사, 32개 셸 재사용, 일시정지·재생, 수면 반사와 화면 안내.
- `Assets/FireflyFestival/Scripts/FireworkShell.cs`: 상승과 폭발 전환, 구형·낙하형·원형·이중 고리·반딧불형 입자 배치, 잔광 정리.
- `Assets/FireflyFestival/Shaders`: URP용 빛·꼬리·밤하늘·호수 셰이더. 외부 텍스처나 추가 유료 에셋 없이 구성했습니다.
- `Assets/FireflyFestival/Editor/FireworksSceneBuilder.cs`: 씬과 에셋을 재생성하는 제작 도구. **Firefly Festival → Rebuild GameScene**을 실행하면 기본 연출로 다시 생성되므로 수동 수정한 씬·팔레트·큐가 덮어써집니다.

이미 저장된 GameScene과 프리팹이 포함되어 있으므로 재생성 도구를 실행할 필요 없이 바로 재생할 수 있습니다. Build Settings에도 GameScene이 등록되어 있습니다.

제작 도구 메뉴에는 **Verify Full Score and Capture Previews**와 **Build Windows Player**도 있습니다. 전자는 실제 음악 재생·일시정지·재개·재시작을 확인한 뒤 전체 발사 큐와 종료 처리를 고정 시간 간격으로 시뮬레이션하고, 후자는 Windows 실행 파일을 만듭니다. 검증 로그·미리보기·빌드는 프로젝트 바깥의 바탕화면 `output/FireflyNocturne`에 저장합니다.

## 참고 및 크레딧

- 수업 참고: 교수님의 **HandsOnPractice / Fireworks** 씬과 `FireworksController.cs`의 시간별 Phase 전환, 상승·폭발·잔광 파티클 구성.
- 본 프로젝트의 연출, 스크립트, 배경 메시, 셰이더는 이 과제를 위해 새로 구성했습니다. 교수님 프로젝트를 의존성으로 요구하지 않습니다.
- BGM: **TTRM — 오랜 전설 이야기 (완성)**. 사용자가 제공한 원본 음원을 사용했습니다. 음원의 권리는 원 저작자에게 있습니다.
- 시작 씬과 패키지 기반: Unity Universal 3D 템플릿.

## 검증 결과

- Unity 6000.3.23f1에서 컴파일 및 실제 Play 모드 음악 재생, 일시정지, 재개, 재시작 확인.
- 335.151초 전곡과 마무리를 고정 시간 간격으로 시뮬레이션: **119 / 119회 발사**, 누락 0회, 마지막 셸과 반딧불 정리 확인.
- 팔레트 배치: 노랑 64회, 연두 49회, 빨강 6회. 최대 동시 사용 셸은 32개 중 10개.
- 주요 6개 구간을 실제 URP 렌더링으로 캡처하고 네 가지 커스텀 셰이더의 컴파일 확인.
- Windows 64비트 빌드 성공, 빌드 오류 0개. 별도 플레이어를 20초간 실행해 시작 구간에서 스크립트 예외 없이 동작 확인.
- 검증은 전곡을 실제 시간으로 끝까지 청취한 테스트와는 구분됩니다. 전체 큐 및 종료 처리는 고정 간격 시뮬레이션으로 확인했습니다.
